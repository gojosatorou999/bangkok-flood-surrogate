- **T31 real bugs found and fixed while verifying the map (not visible from code review alone — needed an actual running browser to surface):**
  1. `.map-container`'s CSS (`position: absolute; inset: 0`) was silently overridden by maplibre-gl's own injected stylesheet (`.maplibregl-map { position: relative }`), since MapLibre adds that class directly onto the container element we hand it and both are single-class selectors of equal specificity — whichever stylesheet loads last in the bundle wins. Collapsed the map to 0 height. Fixed with an inline style (always wins regardless of cascade order).
  2. maplibre-gl's internal Web Worker failed to load under Vite dev's esbuild pre-bundling ("Worker failed to load"). Fixed with maplibre-gl's own documented Vite workaround: `optimizeDeps: { exclude: ['maplibre-gl'] }`.
  3. deck.gl's `MapboxOverlay` with `interleaved: true` shares maplibre's WebGL context/draw calls; when its render hook threw (`Cannot read properties of undefined (reading '_nearZ'/'height')`, from calling `map.addControl(overlay)` before the map's `'load'` event), it sometimes corrupted shared GL state badly enough that maplibre's *own* tile layer intermittently stopped repainting too — not just a dropped deck.gl frame, a blank map. None of this app's layers (a line outline, two point layers, a flat bitmap) need true 3D interleaving with map geometry, so switched to `interleaved: false` (deck.gl draws on its own separate canvas) *and* kept gating `addControl` on `'load'`. Both together were needed: `interleaved:false` alone still broke maplibre's own style pipeline (only `style.json` ever got fetched, never the sprite/tiles/fonts it references) when the control was added synchronously before `'load'`.
  4. The domain-boundary `GeoJsonLayer`'s stroke was pure white (`[255,255,255,220]`) — invisible against the Positron basemap's own near-white background. Confirmed the layer itself was rendering correctly (temporarily set it to solid red to verify) before concluding it was a contrast choice, not a bug, and repainted it dark slate instead.
